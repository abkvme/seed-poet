About Seed Poet

What is Seed Poet?

Seed Poet is a creative tool that generates rhyming poems using exclusively words from the BIP39 mnemonic wordlist - the same 2048 words used to create cryptocurrency wallet seed phrases.

Poem Lengths

  • 12 words - 4 lines, 2 couplets
  • 24 words - 8 lines, 4 couplets

What is BIP39?

BIP39 (Bitcoin Improvement Proposal 39) defines a standard wordlist of 2048 English words used to generate mnemonic seed phrases for cryptocurrency wallets. These words were carefully selected to be distinct and memorable.

Privacy and safety

  • Every poem is made from fresh randomness from the operating system's secure source, and is a valid BIP39 phrase with a correct checksum.
  • The poem is never stored, logged or put in a web address. Nobody else, and no bot, can open it again.
  • It is removed from your page after 15 minutes or as soon as you leave the page, so the next person at the same browser cannot go back to it.
  • No cookies, no analytics, no third-party code.
  • A 12-word poem holds about 88 bits of randomness and a 24-word poem about 176, because rhymes limit word choice. For a wallet with real value, use 24 words, or run Seed Poet offline from its open source code.

Technology

Seed Poet is built with Go using only standard library dependencies. No external services or JavaScript frameworks.
