About Seed Poet

What is Seed Poet?

Seed Poet is a creative tool that generates rhyming poems using exclusively words from the BIP39 mnemonic wordlist, the same 2048 words used to create cryptocurrency wallet seed phrases. Read word by word, every poem is a valid BIP39 phrase with a correct checksum, so any BIP39 wallet accepts it.

Poem lengths

  • 12 words: 4 lines, 2 couplets
  • 24 words: 8 lines, 4 couplets

What is BIP39?

BIP39 (Bitcoin Improvement Proposal 39) defines a standard wordlist of 2048 English words used to generate mnemonic seed phrases for cryptocurrency wallets. These words were carefully selected to be distinct and memorable.

Which blockchains and wallets?

A Seed Poet poem is a standard BIP39 English recovery phrase, so it works with any wallet that lets you import or restore from a 12 or 24-word BIP39 phrase. That covers the most popular blockchains:

  • Bitcoin (BTC), plus Litecoin, Dogecoin and Bitcoin Cash
  • Ethereum (ETH) and EVM networks such as Polygon, BNB Chain, Arbitrum, Optimism, Base and Avalanche C-Chain
  • Solana (SOL)
  • Cardano (ADA): use 24 words, which every Cardano wallet accepts
  • Polkadot (DOT), Cosmos (ATOM) and Tron (TRX)

Wallets that import BIP39 phrases include hardware wallets such as Ledger and Trezor and apps such as MetaMask, Trust Wallet, Phantom and Exodus. The phrase is only the master key: your wallet derives the addresses for each chain from it. Monero is the exception, because it uses its own 25-word seed format.

Privacy and safety

  • Every poem is written by your browser, from your device's secure random source. It is never sent to a server: the site is not even allowed to make network requests from the poem page.
  • The poem is never stored, logged or put in a web address. Nobody else, and no bot, can open it again.
  • It is removed from your page after 15 minutes, when you press "hide now", or as soon as you leave the page, so the next person at the same browser cannot go back to it.
  • No cookies, no analytics, no third-party code.
  • With JavaScript turned off, you can ask our server to write a poem instead. It is shown once and never stored or logged.
  • A 12-word poem holds about 88 bits of randomness and a 24-word poem about 176, because rhymes limit word choice. For a wallet with real value, use 24 words and the offline version.

Technology

Seed Poet is open source under the MIT license. The generator exists twice, in Go and in plain JavaScript with no dependencies, and both produce exactly the same poem from the same random bytes. This website runs the JavaScript version in your browser. The source code is on GitHub.
